## How to use a prompt

1. Open a video’s **Prompt** link and copy the prompt.
2. Give it to Gemini 4 Neon in a coding agent that supports the model, filling in any placeholders such as your product name.
3. Let it write the animation as code, then render it to video (Remotion, HyperFrames, or a headless browser with ffmpeg).

If a video has a **Skill** link instead, follow the creator’s setup instructions.

Want agents that already know timing, easing and choreography? See the [MotionVideo skill](https://motionvideo.xyz/motionvideo-skill?utm_source=github&utm_medium=readme&utm_campaign=awesome-gemini-4-neon-motion-design).
